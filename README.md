# `cowdedroyal-lab/.github`

本仓库用于维护 **Cowdedroyal Lab** 的组织级配置与默认社区规范文件：

- [`profile/README.md`](./profile/README.md) — 组织主页展示内容
- [`profile/assets/`](./profile/assets/) — 组织 Logo 与主页横幅源文件及渲染图
- [`CONTRIBUTING.md`](./CONTRIBUTING.md) — 全组织默认贡献指南
- [`SECURITY.md`](./SECURITY.md) — 全组织默认安全漏洞报告说明
- [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) — 全组织默认社区行为准则
- [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE/) — 全组织默认 Issue 表单模板
- [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) — 全组织默认 Pull Request 模板

> 组织内没有自定义同名文件的公开仓库会自动继承这里的社区规范与模板。
